
# Week 3 - Web Scraping with BeautifulSoup

## Project Description

This project demonstrates basic web scraping using Python. I used Requests and BeautifulSoup to collect book information from Books to Scrape.

The extracted information includes book titles, prices, availability, ratings and URLs.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- CSV

## Features

- Checks robots.txt before scraping.
- Extracts information from book listings.
- Handles website connection errors.
- Scrapes multiple pages.
- Saves collected information into a CSV file.

## How to Run

1. Install the required libraries:

   pip install requests beautifulsoup4 pandas

2. Run the Python file:

   python web_scraping.py

3. The scraped data will be saved in books_data.csv.

https://books.toscrape.com/
